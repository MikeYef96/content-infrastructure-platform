# Vertical Slice Method

Build features end-to-end.

Example:
Database → Prisma → application service → REST endpoint → tests → React UI.

Recommended slices:
1. Organization
2. Application/environment
3. Schema
4. Content entry
5. Draft version
6. Publish
7. Delivery API
8. References
9. Impact analysis
10. Rollback
11. Environment promotion
12. Webhook delivery
